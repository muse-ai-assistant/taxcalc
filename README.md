# 个税计算

中国现行税法下的月度个人所得税计算器，单文件网页应用，打开即用。

👉 在线体验：https://muse-ai-assistant.github.io/taxcalc/

## 功能

- 输入税前月薪、五险一金（月）、专项附加扣除（月），一键计算
- 应纳税所得额 = 月薪 − 5000（起征点）− 五险一金 − 专项附加扣除（负数按 0 计）
- 七级超额累进税率（速算扣除数）自动匹配
- 输出月应缴个税、税后到手、适用税率
- 条形图直观展示应纳税所得额落在第几级
- PWA：可安装到手机/桌面，离线可用

## 技术说明

- 纯前端单文件应用：`index.html`（内联 CSS/JS，无构建步骤）
- `manifest.json` + `sw.js` 提供 PWA 安装与离线缓存
- 图标由 PIL 生成（`icon-192.png` / `icon-512.png`）

## 隐私说明

所有计算均在你的设备本地完成，输入的薪资数据不会上传到任何服务器。

## 免责

计算结果仅供参考，实际应纳税额以税务机关核定为准。
